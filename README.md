# Andra Nooryanto | Portfolio

Personal portfolio website for Andra Nooryanto, an Informatics student interested in programming, web development, computer networking, and cyber security.

## Pages

- `index.html` - Portfolio homepage and featured project.
- `projects/avenqor/index.html` - Avenqor project case study.
- `404.html` - GitHub Pages not-found page.

## Assets

- `assets/images/avenqor/` - Avenqor wordmark and application screenshots used by the project case study.

## Featured Project

[Avenqor](https://github.com/andra-gs/Avenqor) is a local-first project manager for Windows and Android. It organizes workspaces, projects, tasks, deadlines, and documents, and works without an account or an internet connection.

## Run Locally

Open `index.html` in a browser, or serve the repository root with a local static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Built With

- HTML
- CSS
- JavaScript
- [Lucide](https://lucide.dev/) icons
